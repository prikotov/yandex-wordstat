# Yandex Wordstat

> Анализ поисковых запросов через Яндекс.Wordstat

## Зачем это нужно

Этот skill извлекает данные о поисковых запросах из Яндекс.Wordstat. Данные помогают:

- **Подбирать ключевые слова** для SEO и контекстной рекламы
- **Оценивать спрос** на товары и услуги
- **Находить похожие запросы** для расширения семантического ядра
- **Анализировать сезонность** запросов

## Что вы получите

Отчёты в форматах CSV и Markdown:

| Тип | Содержание |
|-----|------------|
| `freq` | Частотность запрошенной фразы |
| `similar` | Похожие поисковые запросы |
| `history` | Динамика показов (день/неделя/месяц) |
| `regions` | Распределение показов по регионам (count, share, affinityIndex) |

## Настройка

> ⚠️ Старое Wordstat API (OAuth-приложение, `client_id`/`client_secret`) закрыто Яндексом.
> Скилл работает через **Yandex Search API v2** — нужен API-ключ Yandex Cloud.

### 1. Сервисный аккаунт и ключ

1. Откройте https://console.yandex.cloud/ — выберите/создайте каталог; к облаку должен быть
   привязан платёжный аккаунт (billing).
2. Создайте сервисный аккаунт и назначьте ему роль `search-api.webSearch.user` на каталог
   (роль назначается именно сервисному аккаунту, не личному пользователю).
3. У сервисного аккаунта: «Создать новый ключ» → «API-ключ», scope `yc.search-api.execute`.

### 2. Конфигурация

Конфиг ищется в порядке: переменные окружения `YANDEX_WORDSTAT_API_KEY` + `YANDEX_WORDSTAT_FOLDER_ID`
→ `wordstat_config.json` в текущей директории → в каталоге скилла (общий ключ для всех агентов
этой установки) → в корне репозитория при раскладке TasK.

```json
{
  "api_key": "AQVN...",
  "folder_id": "b1g..."
}
```

Положите файл в каталог скилла — тогда все агенты, использующие установку, найдут ключ автоматически.
Секретные файлы защищены `.gitignore`; ключ не логируется.

Тариф: 480 ₽ за 1000 синхронных запросов (Wordstat). Подробности, wire-формат и типовые ошибки —
в [references/api.md](references/api.md); шаблон отчёта — [templates/report.md](templates/report.md).

## Использование

### Напрямую через PHP

```bash
# Базовые запросы
php .opencode/skills/yandex-wordstat/wordstat.php "купить ноутбук"
php .opencode/skills/yandex-wordstat/wordstat.php -t similar "seo"
php .opencode/skills/yandex-wordstat/wordstat.php -t history "маркетинг"

# С детализацией по времени
php .opencode/skills/yandex-wordstat/wordstat.php -t history -p daily -c 30 "opencode"
php .opencode/skills/yandex-wordstat/wordstat.php -t history -p weekly -c 8 "ai"
```

### Параметры

| Параметр | Сокращение | Описание | Пример |
|----------|------------|----------|--------|
| `--geo` | `-g` | ID региона | `-g 1` (Москва) |
| `--type` | `-t` | Тип отчёта | `-t similar` |
| `--limit` | `-l` | Лимит записей | `-l 20` |
| `--period` | `-p` | Период для history | `-p daily` |
| `--count` | `-c` | Количество периодов | `-c 30` |

### Типы периодов (для history)

| Значение | Описание | Ограничение |
|----------|----------|-------------|
| `daily` | По дням | Последние 60 дней |
| `weekly` | По неделям | С 2018 года |
| `monthly` | По месяцам (по умолчанию) | С 2018 года |

### Популярные регионы

| ID | Регион |
|----|--------|
| 225 | Россия |
| 1 | Москва и область |
| 213 | Москва |
| 2 | Санкт-Петербург |
| 3 | Центр (ФО) |

Полное дерево регионов возвращает метод `getRegionsTree` (клиент кэширует его для имён регионов).

### Через агента
