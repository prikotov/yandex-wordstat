# Шаблон отчёта Wordstat

Используй эту структуру для отчётов по частотностям (Markdown). Данные бери из CSV/MD,
которые создаёт `wordstat.php` в `wordstat_reports/<дата>/`.

```markdown
# Wordstat: <фраза>

- Дата замера: <YYYY-MM-DD>
- Регион: <Россия / ID региона>
- Окно: последние 30 дней (freq/similar/regions) или <период> (history)
- Источник: Yandex Search API v2, скилл yandex-wordstat

## Частотность

| Запрос | Показы |
|---|---|
| <фраза> | <count> |
| <вариант 1> | <count> |

## Динамика (если запрошена)

| Период | Показы | Доля |
|---|---|---|
| <YYYY-MM-DD> | <shows> | <share> |

## Регионы (если запрошены)

| Регион | Показы | Affinity index |
|---|---|---|
| <regionName> | <count> | <affinityIndex> |

## Выводы

- <1–3 вывода: объём спроса, сезонность, география, длинный хвост>
- Ограничения: показы ≠ клики; запросы ниже порога Wordstat не отображаются;
  «похожие запросы» — ассоциации по аудитории, не семантические синонимы.
```

Правила:
- Числа — только из ответа API, без оценок «с потолка».
- Пустой результат фиксируй как «ниже порога Wordstat», не как «спроса нет».
- Для батчей указывай суммарное число запросов и примерную стоимость (480 ₽/1000).
